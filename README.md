-->Doctor Appointment UI
This app has a simple, minimal interface with three main sections.

-->Add Doctor
- A small form where you enter doctor ID, name, specialization, and max daily patients.
- When you submit, the doctor is added and shown in the list.

-->Doctor List
- A table that shows all doctors.
- It displays each doctor's ID, name, specialization, max daily patients, and current appointments.
- It updates when you add a doctor or book an appointment.

-->Book Appointment
- A form to choose a specialization and enter a patient name.
- The system automatically picks the doctor with the fewest current appointments.
- If all doctors for that specialization are full, it shows a message.
